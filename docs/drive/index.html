Start line

Strip the noise from Claude Code.

cslim reads your repo with a real AST parser and throws away everything Claude doesn't need — function bodies, blob hashes, lockfile churn, ANSI escape codes.

uv tool install --editable . --with textual

Leg 01 — The noise highway

Most of a diff isn't the change.

Blob hashes. --- a/ +++ b/ pairs. Mode bits. Lockfile churn. Whitespace-only reformatting. Claude reads all of it and learns nothing.

cslim diff strips the metadata and keeps the change. cslim clean does the same to test output: ANSI codes, progress bars collapsed to their final state, repeated lines counted.

−57%diff tokens
−60%CI output

Measured. Pure subtraction — nothing is injected, so there is no cache penalty.

Leg 02 — The AST tunnel

Keep the skeleton. Drop the body.

A real ast parse keeps signatures, types, class hierarchies and imports, and elides every function body to ... — 39k tokens down to 9k on cslim's own source.

--index-only

One line per file naming what it defines. A 25-file project fits in 1k tokens — a 98% cut, with no file left invisible.

Reference ranking

A graph of which file references which decides who earns a full skeleton when the budget is tight. The module everything imports explains more than a leaf nobody calls.

Leg 03 — The cache pit stop

Then the benchmarks said stop.

Real Claude Code sessions, reading Anthropic's own total_cost_usd. Every automatic-map configuration cost more than sending nothing.

Cache read0.1×
Cache write1.25×

One freshly injected token costs what twelve cache-read tokens cost. Claude Code's exploration is almost all cache reads, so a map must prevent 12× its own size to break even.

Finish line

Use the two that win.

cslim diff and cslim clean are measured, unambiguous subtraction. The automatic map is a context-window tool, not a cost saver — and the command that enables it says so.
