What it does

Keep the skeleton. Drop the body.

A real AST parser reads your repo and keeps signatures, types, class hierarchies and imports. Every function body goes.

What Claude reads today134 tokens
def copy_to_clipboard(text: str) -> str:
    """Copy text to the clipboard; returns the backend."""
    for name, command in _candidate_backends():
        if not shutil.which(command[0]):
            continue
        try:
            subprocess.run(command, input=text.encode("utf-8"))
            return name
        except (subprocess.CalledProcessError, OSError):
            continue
    try:
        import pyperclip
        pyperclip.copy(text)
        return "pyperclip"
    except Exception as exc:
        raise ClipboardError("no backend ...") from exc

The finding

I benchmarked it. It cost more.

Every configuration of the automatic map cost more than sending nothing. Real Claude Code sessions, reading Anthropic's own total_cost_usd out of claude -p --output-format json. Nothing estimated.

pallets/flask — 80 files, 12 turns, 3 sessions per arm
MapCost / sessionvs control
none$0.7814—
full AST map$0.9729+24.5%
index only$0.9213+17.9%

Control spread ±$0.0820 — both gaps clear the noise.

Why

The caching math

One token of freshly injected context costs roughly what twelve cache-read tokens cost.

Anthropic bills a cache write at ~1.25× base input and a cache read at ~0.1×. Claude Code's exploration is almost entirely cache reads — re-reading a file it already pulled is nearly free. A map has to prevent ~12× its own size in exploration just to break even.

Shrinking the map doesn't help

InjectedExtra cache write
500 tokens+7,014
5,000 tokens+17,384
30,000 tokens+16,734

5k and 30k are statistically indistinguishable. Cost is driven by the act of injecting, not by size.

6.9× the run-to-run spread. Same content, same model — five times the price depending on which door you push it through. The overhead isn't inherent to giving Claude a map; it's specific to the mechanism.

Which mode to use

Two of these are unambiguous wins.

Measured win

Reviewing a diff

cslim diff

Strips blob hashes, lockfile churn and whitespace-only reformatting. Pure subtraction — nothing injected. −57%

Measured win

Debugging test or CI output

cslim clean

ANSI codes stripped, progress bars collapsed to their final state, repeated lines counted. −60%

Buys coverage, costs money

Repo doesn't fit the context window

cslim --index-only

Measured to fit: a 25-file project reaches 1k tokens. It will still raise your bill.

Hypothesis falsified

You want to spend less money

no map

No map configuration beat the control. 12-turn sessions showed the same penalty as 2-turn ones.

Install

Python 3.10+ and git.

git clone https://github.com/nexusstartup1-create/claudeslim.git
cd claudeslim
uv tool install --editable . --with textual
The distribution is cslim. claudeslim on PyPI is a different, unrelated project — don't install that one by mistake. Not yet published; install from source.

Run the benchmarks on your own repository — results that contradict these are the most useful contribution right now.
